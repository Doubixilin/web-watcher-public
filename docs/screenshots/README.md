# 界面素材说明

本目录是公开 README 的界面截图，基于 0.3.0 的 `Dashboard.swift`、`NetworkPanes.swift` 和 `VisualComponents.swift`，通过原生 macOS 窗口截取。

截图采用独立本地预览载入合成模型状态，标题及页面注明“演示数据”。网络名为 `Demo Wi-Fi`、`Demo Backup`、`Demo Guest`；信号、曲线、HTTP 422、进程名称及编号、事件时间与验证结果均为人为构造的示例，不是私人运行记录。预览不执行实际探测、切网、进程采样或系统定位授权，不更改正式应用的偏好与历史。

| 文件 | 展示内容 |
| --- | --- |
| `overview.jpg` | 无线指标、实时上下行与探测耗时趋势 |
| `wifi.jpg` | 当前协议、信号、信道与主备候选来源 |
| `recovery.jpg` | 默认关闭的恢复开关与合成事件时间线 |
| `sites.jpg` | DNS、TCP、HTTPS 阶段结果与 HTTP 业务错误语义 |
| `processes.jpg` | 合成进程的上下行列表 |
| `settings.jpg` | 菜单栏显示模式与物理接口选择 |

这些截图用于介绍已实现的界面，不证明真实网络恢复已验收、进程采样长期稳定或已完成公网测速。完整实现与验收状态以 [会话交接](../HANDOFF.md) 为准。

替换素材时仅截取应用窗口，并检查图片中的文字和图像元数据。不要上传桌面、实际 SSID、地址、代理端点、软件列表、进程信息、原始事件或本机路径。
